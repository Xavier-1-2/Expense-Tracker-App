How to run this application after downloading and unzipping the folder

Step 1: Open the folder in Vs Code and change directories into flutter_applicaion_1 if not done yet
Step 2: Make sure to the Flutter sdk is Installed and Setup on your device 
Step 3: Download the flutter extenstion in vscode 
Step 4: Download the Android Studio application
Step 5: Go into virtual device manager and startup an emulator (preferrably Pixel 5)
Step 6: Connect the flutter device Tab on the bottom right of your screen to the emulator you chose 
Step 7: Type the flutter run command in the vs code terminal and the application will work
